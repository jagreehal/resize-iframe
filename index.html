resize-iframe

Iframes that size themselves to their content — cross-origin included. No build step, no dependencies.

GitHub · npm · Docs

  • ~5 kB, two files
  • Zero dependencies
  • Plain iframe or custom element
  • Two-way messaging
  • srcdoc injection
  • Storage Access API

The custom element

Drop in <resize-iframe src="…"> and the frame tracks its content. The frames on this page are sandboxed without allow-same-origin, so the browser gives them an opaque origin — the parent genuinely cannot reach inside, exactly as with a third-party embed.

<resize-iframe> — height set by the child, capped at max-h waiting for the frame…
Add or remove content inside the frame and watch the height above.

Or a plain iframe

Already have iframes on the page? iframeResize() takes a selector, an element, or nothing at all (every iframe on the page), and hands back a handle with sendMessage() and disconnect().

iframeResize() — with callbacks and two-way messaging waiting for the frame…
Messages between the two pages show up here.

The code behind that frame

import { iframeResize } from 'resize-iframe';

const [frame] = iframeResize({
  direction: 'vertical',       // 'horizontal' | 'both' | 'none'
  offsetSize: 0,
  onResized: ({ height }) => console.log(height),
  onMessage: ({ message }) => console.log(message),
}, '#frame-b');

frame.sendMessage('ping from the parent');
frame.disconnect();            // before you remove the iframe

Inline HTML you generate yourself

When the host builds the framed HTML — a report embed, a quiz, model output — there is no page author to add the child script. withResizeChild() inlines it for you, so the document you hand to srcdoc is self-contained: no CDN, no path back to the package.

withResizeChild() — edit the HTML, the sandboxed frame follows waiting for the frame…
Type in the box — every keystroke rebuilds the document and the frame re-measures.

What that takes

import 'resize-iframe';
import { withResizeChild } from 'resize-iframe/inject';

const frame = document.createElement('resize-iframe');
frame.setAttribute('sandbox', 'allow-scripts');   // opaque origin, keep it
frame.setAttribute('srcdoc', withResizeChild(generatedHtml));
document.body.append(frame);

Idempotent, and a fragment gets wrapped in a minimal document with its margin zeroed — so even a bare string of text has a box to be measured in. Remote src pages are untouched: only that page's author can load the child script.

Why it needs two files

A cross-origin parent cannot measure the page it frames — the browser will not let it. So the framed page measures itself and posts the number up. That is the whole mechanism.

Measures the right box

The child measures the bottom edge of body's children, never body itself, so a frame that grew can shrink back again.

Catches late changes

A ResizeObserver picks up reflow from images and fonts; a MutationObserver picks up DOM and style changes, batched to one measurement per frame.

Ignores everyone else

event.source is set by the browser and cannot be forged, so only the frame's own window is heard — no origin allowlist to configure.

Handles partitioned storage

Third-party frames get partitioned cookies until the user grants access. The child exposes requestStorageAccess() and reports the result to the parent.

API at a glance

In the parentWhat it does
iframeResize(options, target)Connect one iframe, a selector, a list, or every iframe on the page.
<resize-iframe src>Same thing as an element. Also takes srcdoc, min-h, max-h, direction, offset-size, warning-timeout, allow, sandbox.
withResizeChild(html)From resize-iframe/inject. Inlines the child script into HTML you own, ready for srcdoc.
onReady / onResizedCallbacks, or listen for the ready and resize events on the iframe.
onMessage / sendMessage()Two-way messaging on an envelope other postMessage traffic will not match.
onStorageAccessFires when the framed page reports whether it has unpartitioned storage.
disconnect()Removes the listener. Call it before removing the iframe.
In the framed pageWhat it does
parentIframe.sendMessage()Send up to the embedder.
parentIframe.onMessage = fnReceive what the embedder sends down.
parentIframe.resize()Nudge a measurement, for the rare change neither observer sees.
parentIframe.autoResize(false)Stop and start automatic sizing.
parentIframe.requestStorageAccess()Ask for unpartitioned storage. Must run from a click inside the frame.
data-iframe-sizeMark the elements to measure, instead of body's children.
